# 底部播放栏组件

作者：yahyaoo

- `template.js`：静态模板，沿用播放器已有控件 ID 和操作入口。
- `index.js`：同步挂载、事件清理、弹框交互和音量显示。
- `player-bar.css`：主题配色、圆角浮层、桌面与手机布局。

页面只提供 `#player-bar-root`。先加载模板与组件入口，再加载频谱和 `app.js`，避免旧播放器初始化时找不到控件。组件不需要编译或异步请求模板。

`window.playerBar` 提供 `mount(root)`、`destroy()`、`togglePopover(name)`、`closePopovers(restoreFocus)` 和 `updateVolume(volume, muted)`。同一挂载节点重复挂载不会重复注册监听。

歌曲、收藏、队列、下载、音源解析、音频控制和持久化仍由现有业务模块处理。组件只调用原有入口或接收显示状态，不持有独立播放状态。

播放栏为透明毛玻璃浮层，固定在视口底部，不占据页面布局高度。音量在栏内向左展开，暂时覆盖更多、播放模式、收藏和队列，并在收起后恢复；动画遵循系统减少动态效果的偏好。

组件统一测量播放栏遮挡区域，通过 `--player-bar-clearance` 给实际滚动区域追加末尾留白和滚动对齐间距。设置页及其他页面外层仍铺满高度，不按播放栏高度设置 `bottom`；滚动到底部时，最后一项能完整出现在播放栏上方。窗口和播放栏尺寸变化会重新测量，卸载组件会清理监听及补偿变量。

单元测试：`rtk node --test test/playerBar.test.cjs`。系统测试由用户执行，重点检查播放/切歌、封面歌词、来源与音质标签、收藏、更多菜单、进度拖动以及栏内音量展开；同时检查浅色、深色及手机布局，以及页面没有为底栏预留空白。
