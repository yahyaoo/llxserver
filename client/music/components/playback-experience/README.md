# 播放体验组件

队列顶部的设置按钮和设置页“播放队列与列表”共用 `queueOpacity`。
背景不透明度范围为 0–100%，默认 95%；只调整抽屉背景，文字和操作按钮保持实色。
滑块拖动时同步预览，松手后调用原 `updateSetting`，继续使用已有浏览器与账号设置保存链路。

切换歌曲时封面、标题和歌词采用 420ms 淡入位移，队列当前项采用短暂高亮过渡。
同曲音质更新不重播动画；快速切歌取消旧动画；系统开启“减少动态效果”时跳过动画。

`crossfadeDuration` 单位为毫秒，范围 100–15000，默认 1000。
设置页以秒显示并用滑块调整，每次淡入、淡出分别使用该时长。
保持原单音频播放器：切歌先淡出，切换后淡入；暂停和恢复沿用相同时长。
自然播放结尾提前淡出，短音频最多使用后半段。
手动调音量、关闭效果及新播放请求会取消旧渐变，取消时结束旧等待，避免过期暂停干扰新歌曲。

单元测试：`node --test test/playbackExperience.test.cjs test/playerBar.test.cjs test/userInitialization.test.cjs`。
系统验收可检查：两个透明度入口同步及刷新回读、队列切歌过渡、5 秒与边界时长、连续切歌和手动调音量。
