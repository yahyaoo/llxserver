# 独立播放页

页面按入口、静态模板、样式及子组件拆分，沿用原播放器的控件 ID 与事件入口。

- `template.js`：歌词、封面、频谱画布及页面顶部控件的静态模板。
- `PlayerDetailView.js`：页面装配、原底栏控件移动与还原、全屏和竖向音量坐标转换。
- `player-detail.css`：播放页布局与独立的不透明毛玻璃，不读取外部透明度变量。
- `components/PlayerBackground.js`：歌手头像加载、同名歌手搜索回退、账号隔离、过期请求防护与主题色回退。
- `components/Spectrum.js`：原 Wave 分析器数据的底部全宽频谱绘制。

页面由 `index.html` 的 `player-detail-root` 同步挂载，加载于可视化模块和 `app.js` 之前。
进入播放页时移动真实底栏控件，关闭时还原其父节点和顺序，不复制控件或播放状态。
播放、队列、收藏、评论、音效、来源、实际音质、歌词滚动和频谱设置继续由原模块管理。

背景优先使用歌曲附带的歌手头像及现有本地歌手头像接口；本地缺失时复用现有歌手搜索，仅接受同名歌手的头像。
搜索结果按账号、歌手和查询平台缓存，单次搜索限制为 5 秒，不修改歌曲来源和播放状态。
找不到头像时保留主题色，不以专辑封面代替歌手头像。背景使用 28px 模糊和较轻的遮罩，保留头像色彩与轮廓，底色始终不透明。

单元测试：`node --test test/playerDetail.test.cjs test/playerBar.test.cjs`。
