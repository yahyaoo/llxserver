# 洛洛雪音乐 v2.1.4

- 手机播放页调整为封面、歌曲信息、操作入口与播放控制布局，提供全屏歌词，以及独立均衡器和评论页面；手机歌曲行通过更多菜单收起次要操作。
- 修复桌面播放器图标与菜单样式、歌曲库搜索恢复、音效登录会话保存，并调整设置卡片和管理登录间距。
- 统一音乐库、收藏、最近、下载和播放栏的封面加载与持久缓存，旧记录缺少图片地址仍能读取缓存；封面展示不改变内嵌歌词和音频元数据状态。
- 支持持久化默认歌单，完善收藏、歌曲下载、响应式页面和飞牛首次登录初始化。
- 合体飞牛包名称与应用标识统一为 `llxserver.all`，独立服务端和客户端分别为 `llxserver.server`、`llxserver.client`。源码、网页、ZIP、桌面及飞牛版本统一为 `2.1.4`。

## 下载与安装

FPK 适用于 x86_64 飞牛 NAS，依赖 `nodejs_v24`，安装需要联网准备生产依赖。ZIP 分为合体、服务端和客户端；桌面安装包按角色和操作系统提供。附件校验值见 `SHA256SUMS`，来源提交见 `BUILD_INFO.txt`。

旧 `levis.lxserver` 与新的 `llxserver.all` 是不同的飞牛应用，数据不会自动迁移。升级前备份数据，迁移后为对应应用用户授予目录权限；使用相同默认端口的旧应用应先停止。

发布验证包含单元测试、真实 HTTP 与 SQLite 系统测试、三种实际 FPK 安装载荷启动测试及桌面构建。实际 NAS 安装和外部音源播放需在目标设备上确认。
