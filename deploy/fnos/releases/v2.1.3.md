# v2.1.3

基于官方 v2.1.2，本仓库使用补丁号加一的标准版本号。源码、网页与飞牛安装包统一为 2.1.3，发布标签为 v2.1.3。

- 将原 lxserver-source 的自定义功能与 lxserver 的飞牛模板、图标、打包及发布工具整合到当前仓库，直接从根目录构建。
- 支持服务器下载至指定绝对目录，歌词默认内嵌，也可保存同名 UTF-8 LRC；默认沿用播放器歌曲命名方式，支持自定义模板。
- 已下载歌曲优先本地播放，支持 Range 请求、用户隔离和重启恢复。
- 支持自定义缓存目录、后台编辑用户歌曲目录，配置统一保存；保留原有音源实现。
- 移除界面侧栏及右上角原项目标志，保留源码版权和许可证。
- 更新检查默认关闭，可修改服务器地址；默认指向本 GitHub 仓库，兼容以前的自定义版本比较。
- 飞牛模板保留安装存储选择字段、应用用户和共享空间权限。安装包修正 Linux 换行与执行权限，并携带生产依赖锁文件。
- 发布工具使用单仓库附注标签、草稿发布和附件 SHA256 回读校验，支持 GitHub 与 Gitea，拒绝覆盖已有版本。

安装包适用于 x86_64 飞牛 NAS，依赖 nodejs_v24。安装和升级需要联网安装生产依赖。首次安装由系统选择存储位置，升级保留已有应用安装卷。

下载、缓存和自定义歌曲目录需要为飞牛应用用户 levis.lxserver 授予相应权限。切换路径不会自动迁移旧文件。

验证包括源码单元测试、隔离服务器接口系统测试、飞牛载荷测试、发布工具测试，以及实际 FPK 归档和内容校验。实际 NAS 安装与播放请在飞牛上验证。
