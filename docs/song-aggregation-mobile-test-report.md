## 验证范围

公共歌曲身份跨平台聚合，保留版本词及歌手差异；同一路径重复索引只保留一个物理文件。默认选择最高音质，文件面板显示全部位置及音质，切换副本保留播放队列，删除单个或全部文件需要确认。已完成下载按歌曲合并，进行中的下载任务分别保留进度。账号切换期间旧请求不能覆盖新账号目录。

真实 HTTP、SQLite 和文件系统测试覆盖扫描后歌曲主表及文件子表、跨平台同曲三个副本、删除一个副本保留其他文件、重启保留聚合、账号隔离，以及 root/data 同名文件的准确播放与封面读取。两个同名 MP3 使用不同的内嵌图片；指定位置的文件删除后返回 404，不跨位置回退。

浏览器测试使用隔离账号和可控的目录、封面响应，验证 1068 首队列分批渲染后滚动至末尾，末尾歌曲可见且未被手机导航遮挡。封面使用统一候选入口并实际加载图片；390px、700px 最近播放和批量模式没有横向溢出。音乐库更多菜单可以通过真实点击打开文件面板；取消删除不发送请求。

浅色、深色、纯白、纯黑外观分别搭配粉色、白色、黑色配色，共 12 种组合，文件面板正文与背景对比度均不低于 4.5:1。手机字体下拉可操作，字号真实键盘操作立即保存，歌词计算样式应用所选字体，刷新后字体与字号保留。指定字体仍取决于设备是否安装；系统字体选项可直接使用。
