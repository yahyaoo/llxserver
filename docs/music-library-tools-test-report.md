# 音乐库工具栏、后台维护与漫游测试报告

作者：yahyaoo

日期：2026-10-12

## 实现范围

- 音乐库移除标题旁扫描状态，刷新和更多菜单扫描接入进度条。
- 更多菜单提供整库歌词补全、歌词嵌入、元信息补全；批量栏保留全选、清空、删除、退出，删除先确认。
- 单首歌曲操作统一为喜欢、收藏、更多。自定义目录使用同一入口；下载、最近、收藏和歌单复用维护模块。
- 文件维护使用 Node 工作线程；服务端按账号保存进度。一个账号的维护任务串行互斥，重复请求返回 409；不同账号互不干扰。
- 公开库维护要求有效管理员会话；个人库检查账号归属及自定义目录写入、删除权限。客户端不能传任意磁盘路径。
- 吸顶工具栏复用原按钮节点，保留事件。歌单总览为独立页面组件，封面正方形；收藏歌手与专辑使用方块布局。
- 漫游核心独立，使用基础权重加个人有效播放次数和可选模型附加权重。排除当前歌曲；累计与最近列表分开，清空最近不清空累计。首次读取兼容已有次数。
- 播放模式菜单提供漫游及爱心波纹图标；恢复模式、切换账号与有效播放提交后刷新权重。

## 验证

- `npm run test:unit`：280 项通过，无失败。
- `npm run test:system`：23 项通过，无失败，包括真实 HTTP、SQLite、扫描、维护任务及下载回归。
- 新增工作线程测试真实写入和回读 MP3 中文歌词、标题、歌手、专辑，并验证已有嵌入歌词跳过、逐项错误汇总、互斥和账号隔离。
- 真实维护接口测试验证 30 个本地文件、重复任务拒绝、跨接口获取同一任务、单首删除不影响其他文件、公开库权限及漫游会话去重。
- 浏览器脚本 `test/musicTools.browser.cjs`：44 项通过，覆盖菜单内容、筛选选中态、15 种外观与配色组合对比度、列表吸顶、跨页进度、歌单详情跳转、方块封面、下载维护请求和手机布局。
- `git diff --check` 通过。

首次全仓回归 307 项中 306 项通过，手机菜单测试失败源于测试 DOM 对未知选择器的模拟不准确；修正模拟并新增音乐库单层菜单用例后，单元和系统测试入口均通过。

## 验证边界

浏览器使用隔离账号服务、模拟歌曲与任务进度，验证真实页面交互及请求结构；网络平台歌词供应不作为本次浏览器测试依赖。工作线程文件操作和服务端权限由真实文件、HTTP、SQLite 测试覆盖。

任务状态在服务进程内保存，支持切页和刷新恢复；服务重启不续跑未完成任务。未关联网络音源的歌曲会明确报告歌词获取失败，不猜测歌曲对应关系。元信息补全沿用已关联歌曲的元信息写入规则。
