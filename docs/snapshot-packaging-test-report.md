# Snapshot 测试包验证

验证日期：2026-10-10；源码分支：`dev`。

本次提交包含账号会话与 Token、歌单导入、下载页面、歌曲文件状态、歌词设置、移动导航和默认账号数据初始化等待提交功能。新增 `.github/workflows/snapshot.yml` 仅响应 `v*-snapshot.*` 标签，以读取权限构建并上传 Actions artifacts，保留 30 天。测试包包含整体、服务端、客户端的 Node ZIP 和飞牛 FPK，以及提交信息和 SHA256 校验文件。

## 打包检查中修复的问题

- 会话存储明确拒绝未配置密码的本地账号；用户配置补齐昵称与头像版本默认值，修复 TypeScript 编译错误。
- 头像服务运行时依赖 `sharp`，将其从开发依赖移至生产依赖并同步锁文件，避免生产安装漏装后无法启动。
- ZIP 与 FPK 启动测试使用真实管理员和账号登录，验证新版会话门禁、拆分网关、数据库及页面访问。
- 更新已改变且有接口测试覆盖的 9 个路由处理器语句基线，保留其余处理器及 160 个既有路由条件和顺序校验。

## GitHub 首轮构建反馈

首轮标签保留用于追溯，修复后创建新的 snapshot 标签，不移动或覆盖已有标签。

- Linux Node 24.21.0 上的 `better-sqlite3 11.10.0` 在测试进程退出时触发原生析构断言。更新为支持 Node 20、22、24 的 `12.11.1`，重新验证数据库、迁移和接口。
- 桌面交付目录缺少主页与仓库元数据，补齐后供 Electron Builder 读取；Linux 维护者使用已有作者名。
- Electron Builder 明确使用空发布配置，避免测试包自动更新元数据生成报错；保留 `--publish=never`。
- 架构由打包脚本逐个传入，目标配置不再列出额外架构，确保每个后端包匹配对应 Node 运行时。
- 桌面构建环境使用 Node 22.22.3，与随包运行时一致，满足现有 Electron 和依赖要求。

上述修复后，本机重新构建通过，175 项单元、15 项系统、3 项真实 FPK 系统测试通过；新增桌面打包回归与原桌面测试共 8 项通过。GitHub Node 24 与各桌面平台的实际结果以新标签构建记录为准。

## 合体 FPK 命名与身份修正

合体 FPK 的文件名、模板目录、manifest 应用 ID、桌面启动入口、应用用户/组及共享目录统一为 `llxserver.all`。独立包仍为 `llxserver.server` 与 `llxserver.client`，Node ZIP 保持 `llxserver-all`、`llxserver-server`、`llxserver-client`。

更新 snapshot 收集路径、发布脚本、图标生成路径、忽略规则及真实 FPK 测试。新增归档回归测试拒绝旧 ID 或内部身份不一致的包，防止只修改产物文件名。新应用身份的旧数据迁移说明见部署文档；历史发布说明保留原标识。

本轮修正后的构建通过，176 项单元测试、15 项系统测试、8 项打包测试、3 项真实 FPK 系统测试及 8 项发布脚本测试全部通过。合体包回读核对 manifest、应用用户/组、共享目录和桌面入口，均为 `llxserver.all`。构建过程中清理 `dist` 曾影响并行测试加载；构建完成后完整重跑通过。
