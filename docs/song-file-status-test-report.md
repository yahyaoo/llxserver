# 歌曲文件状态与下载入口验收

日期：2026-10-10；开发分支：dev。

## 改动

- 新增后端文件状态组件和 `POST /api/music/file-status`，复用现有 SQLite 索引、下载记录及自定义目录扫描。逐文件核实存在、非零大小、索引大小和目录边界。
- 歌名旁显示绿色下载、蓝色缓存、灰色云端图标；中文 title 和 aria-label 描述状态。查询失败显示问号，不误标为未下载。
- 收藏、个人与导入歌单、在线搜索与专辑、歌手歌曲、在线歌单、排行榜、最近播放、本地音乐库和自定义目录共用前端组件。
- 每页批量查询，超过 500 首分批。翻页旧响应与切换账号响应不覆盖当前节点；可见页面每 15 秒复查，服务器下载完成后触发刷新。外部新增自定义文件最多等待一次扫描与页面刷新。
- 删除旧手动缓存下载选项和“仅下载模式”设置；浏览器下载及指定目录服务器下载保留。单曲、播放栏和批量下载使用现有共用下载浮层。播放缓存与已有文件继续可用。

## 验证

- 新增 10 项单元测试：平台身份、状态优先级、标签匹配、分页批量、异步隔离、错误状态、下载去向、非法路径、空文件、大小不符及越界目录链接。
- 新增真实 HTTP 系统测试：四类文件来源、平台与用户隔离、SQLite 下载记录迁移、重启恢复、删除文件、非法字段及请求大小限制。使用临时数据库和音频文件，不连接现有音乐库。
- Playwright 浏览器验收 11 项通过：真实排行榜三种状态、中文说明、两个下载位置、收藏与导入歌单、在线歌单、手机图标宽度、无横向溢出、设置删除及故障状态。
- 桌面截图：`output/playwright/song-file-status-desktop.png`；手机截图：`output/playwright/song-file-status-mobile.png`。
- `rtk npm run test:unit`：174 项通过，0 失败。
- `rtk npm run test:system`：15 项通过，0 失败。完整日志保存在 `output/song-file-status-unit.log`、`output/song-file-status-system.log`。
- 回归期间修正测试清理的 Windows 文件锁重试及最近播放设置断言的账号作用域；不改变对应业务行为。

## 审查

- 前后端使用相同路径、请求字段、响应顺序和状态枚举；沿用现有账号请求封装与远端代理。
- 检查不接受客户端路径，不跨账号查询，不暴露文件路径或凭据。自定义目录扫描失败向状态查询传播，避免误报云端。
- 保留工作区其他修改；未执行单独编译、提交或推送。系统回归包含项目已有 ZIP 启动验证。
