## 数据与账号关联

| 播放库表 | 内容 |
| --- | --- |
| `client_appearance` | 主题、外观模式、自定义色、透明度、毛玻璃强度、背景引用/位置/模糊度 |
| `client_recent_setting` | 账号最近播放保存上限，默认 100 条，独立于主题表 |
| `client_recent_play` | 最近歌曲和播放时间，有序存储；移除临时 URL 认证参数 |
| `client_artist_group` | 歌手分组、稳定标识、原始名称、歌曲关系、头像查找元数据 |
| `client_album_group` | 专辑分组、稳定标识、原始名称、歌手与歌曲关系 |

沿用项目文档仓储，记录以 `document_key` 对应用户空间；业务数据根内保存相对路径。控制器从认证 Token 获取账号，再由账号目录生成作用域，不能用正文用户名或伪造的用户名请求头覆盖其他用户。公开空间沿用 `_open`，受限模式下修改其主题需要管理员身份。

主题独立存储，避免混进 `client_settings`；最近保存上限也不混入主题表，接口聚合返回只供页面同步。浏览器 localStorage 只缓存按账号分开的外观数据，服务端响应是最终来源；切换账号会清除搜索结果、头像缓存并加载所属主题、最近记录。

面板透明度 `opacity` 为 0–1：0% 完全不透明，100% 背景透明且保留边框；默认 18%。CSS 背景混合比例取 `1 - opacity`，文字和按钮不降低不透明度。覆盖普通页面、左侧菜单、顶部与底部播放栏；播放详情及其底栏保留独立效果。毛玻璃 `glassBlur` 为 0–100，默认 60%，映射到 0–40px 的背景滤镜；0% 为不模糊。图片背景 `background.blur` 仍独立控制图片，不受毛玻璃滑块影响。两种强度与透明度均按账号保存在主题表。

图片位于现有缓存根下的账号目录 `theme-backgrounds/`，头像位于 `artist-avatars/`。图片按内容哈希命名，只在数据库保存文件标识，便于跟随已配置的缓存路径。应用安装入口沿用 PWA 标准事件，浏览器可安装时显示。

歌手和专辑独立表目前保存可重建的曲库分组缓存。歌手按原始名称区分，专辑按名称与歌手区分；稳定 ID 来自原始身份，保留 `rawNames` 供后续别名整理。当前不会自动把「张华」「张崋」或繁简字合并为同一个人。未来的人工聚合需要显式身份映射，不能仅凭字形猜测。

客户端所有应用表和元数据表采用 `client_`，管理域采用 `server_`；初始化 SQL 全字段有中文注释。没有旧表名兼容。系统 config.js 的旧业务字段只通过管理页显式导入，见 [系统配置说明](./system-configuration.md)。

## 接口

| 方法与路径 | 用途 |
| --- | --- |
| `GET/PUT /api/user/appearance` | 读取、保存账号主题；保存时归一边界值并裁剪最近记录 |
| `POST /api/user/appearance/background` | 原始图片请求体上传，返回哈希文件标识 |
| `GET /api/user/appearance/background` | 认证读取当前背景 |
| `GET/POST/DELETE /api/user/recent` | 读取、记录、清空当前账号最近播放 |
| `GET /api/music/library/search?q=关键词` | 检索所属账号本地缓存/下载目录和自定义曲库 |
| `GET /api/music/library/avatar?name=歌手名` | 获取本地分组对应的缓存头像 |

真实滑块验证透明度 0%、50%、100%：计算背景分别为实色、0.5 和 0 的 alpha；毛玻璃 0% 为 `blur(0px)`，50% 为 `blur(20px)`；刷新恢复，播放章节最近上限可保存并裁剪。打开原播放详情及他人新版详情时，外部配置改变不影响详情背景和底栏。
