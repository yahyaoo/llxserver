# 图标与主题可读性检查

作者：jingyh。日期：2026-10-11。

高级筛选的红点是启用筛选标记。Element 的按钮子 span 布局覆盖了 hidden，导致没有筛选时仍显示；现已修复隐藏优先级，并同步桌面和手机标记。筛选条件、数据查询及播放逻辑保持原样。

透明图标按钮不再根据 hover 背景被识别为实色主按钮。普通操作使用主题文字色，选中和悬停使用可读强调色；实色主按钮依据实际主题颜色选择黑白前景。修复了榜单固定黑字、设置帮助图标、头像占位、空状态、标签、消息及说明文字的明暗适配。

对比度基于真实浏览器计算样式，合成透明背景及元素自身透明度。普通文字要求至少 4.5:1；大字和图标要求至少 3:1。禁用、隐藏、遮挡和视口外的元素不作为可操作内容计入。渐变背景使用端点平均色取样，本检查不等于对任意自定义图片背景逐像素的认证。

## 重复执行

在隔离测试服务登录后，通过 Playwright 的文件执行入口依次运行 `test/themeReadability.browser.cjs`、`test/themePagesReadability.browser.cjs`、`test/themeInteractionReadability.browser.cjs`。首个脚本注册共享审计函数并禁用测试期间的动画，后两者复用它；发现不合格元素时抛出错误，附带主题、页面、元素和对比度。重新加载页面即可清除临时审计状态。

默认页面脚本检查所有配色的明亮和暗黑模式；可以在测试浏览器设置 `window.__readabilityThemes`、`window.__readabilityAppearances` 为数组，定向检查纯色外观或问题组合。

本次未执行编译、安装包构建、snapshot、发布或生产环境部署。
