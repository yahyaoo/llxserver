# 播放器呈现与歌词同步验证

作者：jingyh
日期：2026-10-12

## 改动

- 播放加载移到歌曲标题位置，显示“正在加载中 N%”；百分比表示准备阶段，不是文件下载比例。按准备、链接解析、元数据和可播放事件推进；成功、失败或取消后恢复歌曲名。旧请求不能覆盖新请求。
- 歌词通过公共 PlaybackLyrics 会话加载、去重和发布；底栏仅呈现当前句和下一句，详情页共用相同解析数组和行号。修复元信息更新清空底栏歌词、内嵌歌词状态未同步和旧请求覆盖问题，兼容只有逐字歌词的数据。
- 来源与音质标签放到歌手、专辑之后，桌面和手机均使用相同节点。
- 恢复最近播放与本地分组详情的排序、批量、搜索入口；主列表、音乐库、排行榜表头统一按钮尺寸。最近列表排序只改变当前展示，不持久化数据；批量入口复用已有歌曲操作。
- 歌曲列表喜欢按钮与底栏统一红心颜色，避免通用 Element 选中样式覆盖。

## 验证

- npm run test:unit：275 项通过。
- npm run test:system：22 项通过，使用隔离数据库与接口测试。
- test/playerPresentation.browser.cjs：59 项检查通过。静音 WAV Blob 实际播放，隔离歌词响应；覆盖歌词同步、元信息更新、桌面与手机可见页面、最近表头操作、加载失败恢复。
- 浏览器覆盖 light、dark、pure-white、pure-black、system 外观与 pink、white、black 配色，共 15 组，断言实际模式与喜爱颜色。
- git diff --check：通过。
- 不执行编译或打包。音源平台真实歌词响应由用户部署环境验证；浏览器回归使用确定的测试歌词，不调用真实平台。
