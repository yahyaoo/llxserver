## 需求复核

| 原需求 | 本轮确认的结果 |
| --- | --- |
| 后台参考播放器设置重新分组 | 「服务与访问」「音乐与缓存」「同步与数据」目录；切换分组保留表单草稿 |
| 补齐 config.js 业务字段 | 自动检查默认字段与管理入口，用户列表通过用户管理维护；补齐端口、绑定地址、匿名统计、缓存、Subsonic 转码等字段 |
| SQLite 唯一业务配置来源 | 配置读取与保存使用 `server_config`；不加载、监听或自动导入旧 config.js 的业务字段 |
| 显式导入旧配置 | 管理页选择 JS/JSON 文件，通过静态解析、字段校验和事务写库；不执行上传代码、不导入数据库路径 |
| config.js 只保存核心引导 | 两库路径及独立客户端连接字段；移除旧 `database.*` 路径键回退 |
| 双库迁移及回滚 | 不存在的目标复制包含 WAL 的一致快照并初始化；已有同类库校验后直接使用；全准备成功才切换，失败保留旧连接和已有目标文件 |
| 表名规范 | 播放库所有应用表 `client_`，管理库所有应用表 `server_`，元数据表与索引同步调整；没有旧表名兼容读取 |
| 初始化 SQL 注释 | `sql/admin/001_initial.sql` 与 `sql/music/001_initial.sql` 的全部字段均有中文注释，脚本可创建真实数据库 |

管理库已有 SQL 记录的作用域转换仍在数据库内部完成，不读取旧 config.js。原歌曲、歌单 JSON 迁移属于既有音乐业务，本轮保留。

## 范围与限制

测试使用临时数据和独立端口，没有操作用户正式数据库。外部音乐 SDK 初始化隔离，第三方响应使用可控测试数据；未验证真实平台联网播放、WebDAV 云服务、ffmpeg 转码或实际 NAS 安装。

现有桌面包测试验证已生成包的运行与停止，不代表本轮源码已重新打成桌面安装包。本轮没有重新构建桌面安装包或 FPK；飞牛结果为构建、归档和发布工具的自动测试。

代码图覆盖检查提示相关文件 `metadata_changed`；结构审查回读源码，不以代码图结果证明完整覆盖。共享工作区中的他人修改予以保留。
