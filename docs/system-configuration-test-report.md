## 配置与存储覆盖

- 验证所有默认业务字段有对应管理入口；用户由用户管理页面维护，三态细分代理继续使用模式控件。
- 验证缓存命名选项与现有 5 种业务常量一致，歌手抓取页数和转码配置可读取、保存。
- 修改或删除旧配置文件不改变 SQL 业务配置；引导数据库路径不写入业务配置表。
- 旧配置静态解析支持中文、转义、Unicode 码点、字符串续行、注释、undefined 和尾逗号；拒绝执行表达式、危险属性、重复键和含糊的旧式八进制字符串转义。
- 配置与用户在同一个管理库事务中覆盖；错误字段或模拟 SQL 故障不会部分写入。未提供的字段保留，导入数据库路径忽略。
- 管理配置导入不会覆盖播放库；播放器设置导入继续通过独立接口。真实用户登录和旧管理密码失效均有 HTTP 断言。
- 迁库复制包含 WAL 已提交记录；保留仓储对象引用和作用域；两个库切换后立即可读写，重启仍按新路径读取。
- 第二库复制失败、引导写入失败、路径冲突、目标文件已存在及父目录无效均保持旧库可用；迁库失败也恢复本次请求修改的内存配置。
- 配置导出备份、下载、恢复及重启后取值一致；恢复不会改变数据库引导路径。
- ZIP 与 WebDAV 排除当前引导、旧配置副本、实际数据库和 WAL/SHM，包括 Windows 大小写路径；系统 SQL 配置文档可正常同步。
- 飞牛安装向导将密码初始化到 SQL，包含特殊字符的密码保持原值；重复安装不覆盖已有配置。
