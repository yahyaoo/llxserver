## 已完成调整

- 强制账号登录、绑定或远程服务器登录、记住我和服务端有效期配置；退出回登录页。
- 独立账号设置分组，账号资料、迁移洛雪配置、Token 配置分别为子菜单。
- 去掉设置内容顶部小分组标题，统一设置项图标和问号、版本更新及迁移按钮、密码表单样式。
- 登录名只读；展示用户名默认登录名，最多 40 字。头像支持拖动、缩放、方向键定位及取消。
- 所有 /api/ 业务请求统一要求 Session 或 API Token；只放行 POST 登录和凭据验证入口，OPTIONS 为无数据跨域预检。管理员口令头无法单独绕过登录，后台登录签发独立会话。
- API Token 入库按账号关联，保存摘要和加密原值；总开关、禁用、删除、到期、改密撤销即时生效。账号删除撤销全部旧凭据，同名重建不复活。旧 JSON 仅首次迁移，损坏文件不覆盖也不影响其他账号。
