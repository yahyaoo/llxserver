# 加载动效调整与验证

日期：2026-10-12。作者：jingyh。

## 调整范围

- 新增 `client/music/components/loading-state` 公共组件，提供页面、区域、紧凑三种展示；页面加载在可用内容区中央显示圆环和五条音乐律动。
- 接入最近播放、在线搜索/热搜、歌单、歌手/专辑详情、排行榜、音乐库、自定义目录、歌词、评论、缓存、同步及全局遮罩。
- 标题、侧栏、歌词小窗和播放缓冲使用紧凑动效；旧按钮中的转圈图标统一为细线旋转。
- 后台关于页、备份列表初始状态及恢复遮罩复用公共组件。
- 沿用原有请求、分页、账号隔离、加载显示/隐藏及错误处理；状态文字按纯文本转义。
- 动效和文字使用主题前景色，支持减少动态效果偏好；未运行编译、打包或发布。

## 验证结果

- `npm run test:unit`：267 项单元测试通过，含 4 项新增加载组件回归。
- `npm run test:system`：22 项真实接口/SQLite 系统测试通过。
- `test/loadingState.browser.cjs`：在当前源码服务和一次性账号上运行，71 项断言通过。
- 浏览器验证覆盖桌面 1440×900、手机 390×844、14 种配色 × 明亮/暗黑/纯白/纯黑四种外观、全屏遮罩、按钮与歌词小窗、减少动态效果及真实接口完成后的列表恢复。
- 最近播放接口仅延迟响应，结果仍来自真实服务。临时配置、数据、日志和服务均与正式环境隔离。
- `git diff --check` 通过。
