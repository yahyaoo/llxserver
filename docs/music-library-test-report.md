# 多目录音乐库改造验证记录

验证日期：2026-10-11。测试使用隔离目录、真实 SQLite 和 HTTP 服务；没有修改 NAS 的应用、配置或音乐文件。

## 实现与兼容

- 移除 WebDAV 页面、接口、客户端、同步实现和依赖；旧配置中的 WebDAV 字段不再展示或使用。本地 ZIP 备份保留，并备份目录子表。
- 每用户目录保存到 `server_user_music_directory`。旧单目录可迁移，目录标识稳定，重命名账号保留音乐索引与平台关联。
- 保存前实际检测目录读取、临时文件创建、读取和删除权限；不存在或无法读写的目录拒绝保存。目录频率默认 30 分钟，可设为 1～1440 分钟。
- 统一音乐库展示目录、缓存和后端下载文件；扫描位于工作线程，手动请求返回 202，支持进度和首次空库提示。各目录独立计算扫描周期，重复请求复用任务。
- 封面、歌词和标签读取移到受限并发的工作线程，减少重复索引加载与无效封面请求。移动端限制模糊效果及行渲染。
- 播放记录按账号在浏览器暂存，每 15 秒上报，重试沿用播放标识；设置立即在本地生效并合并上报。仍须实际成功收听严格超过 10 秒，单次播放只计一次。
- 本地对象保留真实音质、位深、采样率及文件定位。恢复播放重新构建当前认证 URL，旧恢复事件不会将旧进度套到新歌。

## 真实音源与浏览器

使用用户授权音源，在隔离服务中完成脚本上传、启用、搜索、解析和真实服务器下载。实际下载文件为 4,317,292 字节，下载及本地文件 Range 响应通过；音源密钥、解析地址、账号令牌均不进入仓库和安装包。

浏览器在 390×844 视口验证统一列表、可点击手动扫描、顶部完成状态、真实 WAV 播放、最近统计上报和旧下载事件补全。WAV 实测 `paused=false`、`readyState=4`、14 秒时长；播放后最近记录增加一次且保留目录定位。真实歌曲播放详情显示封面、歌词和进度，播放媒体状态正常。QA 中发现并修复音乐列表被多余 HTML 闭合标签移到容器外、遮挡扫描按钮的问题。

## 本地扫描响应测量

临时目录含 600 个有效 WAV 文件。该次扫描约 650ms；扫描期间 21 次最近记录接口请求平均约 3ms、最大 8ms，完成后核对 600 个索引条目。此测量仅证明本次本机样本下扫描没有拖住该接口，不代表 NAS 大库、网络延迟或真实手机 GPU 性能。

## NAS 只读日志观察与验证边界

SSH 日志观察到自定义本地歌曲尝试在线歌词、音源与评论平台接口时出现不支持平台的提示，以及较多封面请求；应用当时 RSS 约 2.34GB。未发现能单独证明最近统计异常根因的服务端堆栈。代码与浏览器测试已修复可复现的本地定位、下载 ID、延迟队列、无效平台请求及恢复播放问题。

NAS 尚未部署本次 snapshot。移动验证是桌面浏览器窄视口；未在用户的真实骁龙手机上测量帧率。旧浏览器队列缺失封面状态时仍可能产生一次无封面 404；重新从扫描结果播放的条目会使用明确的缺失状态。
