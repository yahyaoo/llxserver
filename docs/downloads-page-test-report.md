# 下载管理独立页面与下载浮层测试

日期：2026-10-10；dev 分支。使用隔离账号服务、临时数据库和测试音频，不修改部署数据。

## 完成内容

- 主菜单按在线搜索、在线歌单、排行榜、最近、收藏、音乐库、不喜欢、下载管理排列，下载管理位于歌单分组前。
- 下载管理改为独立列表页；顶部避让复用音乐库的 --top-bar-clearance；批量操作使用紧凑彩色按钮。
- 单曲和批量下载共用按钮浮层，在同层选择下载位置、音质与歌词；取消、Esc、外部点击均不登记任务。
- 音乐库缓存与自定义目录下载直接访问部署服务器原文件接口，不调用云端歌曲解析。支持中文文件名及子目录。
- 保留队列同步、暂停、继续、重试、歌词补全、清空等既有功能和权限限制。

- 音乐库真实下载得到 33370 字节 MP3，与服务器测试文件逐字节一致，保留原始中文文件名。
