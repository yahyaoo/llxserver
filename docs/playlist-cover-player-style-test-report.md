# 歌单封面与播放栏调整验证

验证日期：2026-10-11；开发分支：dev。保留任务开始前已有的未提交改动。

## 实现

- 播放栏普通区域打开播放详情，标题和歌手不再搜索；按钮、进度轨道及音量控件独立操作。
- 桌面播放栏显示当前和下一行歌词，使用原歌词时间轴自动切换，并支持进度跳转；小屏隐藏底栏歌词以保留操作空间。
- 新建和编辑歌单共用封面、名称表单。支持 JPG、JPEG、PNG、WEBP，限制 5MB；上传内容入库。
- 自定义歌单侧栏显示封面，封面右侧三个点菜单提供编辑、删除。删除保留确认步骤。
- SQLite 新增 client_playlist_cover 表，包含可查询的 cover 列；数据库启动自动补表，按账号和歌单隔离。
- 自定义图片失效或移除后回退第一首歌曲封面，再回退应用默认封面。
- 顶部搜索仅在线搜索页显示，歌单、收藏、排行榜、最近、音乐库、下载和设置隐藏。
- 修复未加载音频时拖动进度条导致无效 currentTime 的边界错误。
